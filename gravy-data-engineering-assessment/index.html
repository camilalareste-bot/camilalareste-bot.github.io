Design decisions

Late-arriving dataRe-read a configurable lookback window behind the persisted watermark, then upsert by provider + pair + timestamp.
Semantic failoverA reference-rate provider cannot silently replace an OHLC workload. Eligibility is capability-aware.
Data qualityValidate at ingestion and again in dbt. Invalid records are quarantined with reasons instead of silently entering marts.
ObservabilityTrack throughput, freshness, retries, provider latency, rejected rows, and run-level metadata.
SecurityNo API keys in source. Production credentials belong in a managed secret store with least-privilege access.
