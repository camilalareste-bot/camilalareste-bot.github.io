Production decisions

Late-arriving and corrected dataRe-read a configurable lookback window behind each persisted provider/pair watermark, then upsert by provider + pair + timestamp. A content hash allows corrected values to replace stale rows without harming idempotency.
Semantic failoverA reference-rate provider cannot silently replace an OHLC workload. Provider selection is capability-aware.
Data qualityValidate at ingestion and again in dbt. Invalid records are traceable through quarantine rather than silently entering analytical marts.
Analytical modelingDaily, weekly and monthly returns; rolling volatility; 7/30/90 moving averages; and provider-level DQ/freshness metrics.
Security & deliveryNo credentials are published here. The supplied company repository remains private to the assessment package; this page exposes only independently created demonstration material.
